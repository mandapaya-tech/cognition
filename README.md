# Cognition Industries

Sitio web estático para cognitionindustries.com. Incluye imágenes conceptuales de tareas robóticas y un corto de 30 segundos.

## Publicación en Cloudflare Pages

Conectar mandapaya-tech/cognition en Cloudflare Pages y elegir la rama principal.

- Framework: None
- Comando de compilación: dejar vacío
- Directorio de salida: .

Después del primer despliegue, añadir cognitionindustries.com en Custom domains y completar la configuración DNS indicada por Cloudflare.

El formulario prepara un mensaje de WhatsApp para que el visitante lo revise y envíe. No almacena datos ni procesa compras. La interfaz de Phylax AI y las escenas representan el concepto del servicio.
