Versión actual del sitio

El código propio de esta web no incorpora píxeles publicitarios de Meta o Google, cookies de marketing ni almacenamiento local para el formulario o el idioma. El cambio de idioma funciona en la página abierta. El navegador puede conservar historial, caché o autocompletado según tu configuración.

Analítica de Cloudflare

La página publicada carga Cloudflare Web Analytics para medir visitas y rendimiento. Cloudflare describe esta herramienta como una analítica que no utiliza cookies, localStorage ni huellas digitales para identificar visitantes. Esto no significa que no se procese ningún dato técnico al conectarse a la infraestructura que entrega el sitio.

Seguridad y servicios externos

Las funciones de seguridad y entrega de Cloudflare pueden emplear tecnologías técnicas según la configuración y el tipo de conexión. Al abrir WhatsApp, sus cookies y otras tecnologías se rigen por sus políticas, fuera de esta web. Consulta la documentación de cada servicio para conocer su uso.

Tus controles

Puedes administrar cookies y datos de sitios desde tu navegador y utilizar sus controles de privacidad. Algunas restricciones pueden afectar servicios externos. Esta web no muestra una opción de “aceptar todas” para herramientas publicitarias que no incorpora. Si se añaden tecnologías opcionales que requieran autorización, se implementará el mecanismo correspondiente antes de activarlas.
